# Cloud Platform Lab

A production-style multi-service application deployed on a local Kubernetes cluster.

## Goal

Build and operate a containerized application locally using Docker and Kubernetes, while practicing:

- Containerization
- Kubernetes deployments
- Networking
- Persistent storage
- Health checks
- Resource management
- Autoscaling
- Helm
- Observability
- Security
- Failure recovery

## Environment

- Windows
- Docker Desktop
- Kubernetes
- kind
- kubectl
- Helm
- Git
